## 🛠️ Built With
* **HTML5** – Structured semantic markup.
* **CSS3** – Custom styling, CSS Flexbox layout, and horizontal scroll configuration.

## ✨ Features
* **Modern Navbar:** Fixed navigation with smooth links to sections.
* **Hero Section:** Engaging introductory banner welcoming visitors to the agency.
* **Horizontal Scrolling Breed Cards:** Clean flexbox layout showcasing featured horses with individual cards, images, descriptions, and adoption action buttons.
* **Responsive Design:** Styled to look neat across different device layouts.
